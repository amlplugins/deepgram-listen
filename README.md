# @amlplugins/deepgram-listen

Native `@deepgram/sdk` SDK re-exported under the `@amlplugins` namespace.

> Deepgram Listen (STT) — Nova-3 transcription (prerecorded) with diarization, smart formatting, redaction.

## Install

```bash
npm install @amlplugins/deepgram-listen
```

## Use

```ts
import { /* named exports from @deepgram/sdk */ } from "@amlplugins/deepgram-listen";
// or
import sdk from "@amlplugins/deepgram-listen";
```

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
